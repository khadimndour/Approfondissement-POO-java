# TP3 – Installation, configuration et test de MySQL

**Établissement :** ESP de Dakar  
**Filière :** Licence 3 GLSI

## Objectif du TP
Installer, configurer et tester MySQL Community Server et MySQL Workbench.

## Travaux réalisés
- Installation de MySQL Server et MySQL Workbench.
- Création de la base de données `tp13`.
- Création de l'utilisateur `esp`.
- Attribution des privilèges.
- Création et test de la connexion `esp_connexion`.
- Vérification et visualisation de la base dans Workbench.

## Livrables
- Captures d'écran des manipulations.
- Fiche de configuration MySQL.
